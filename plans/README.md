This directory contains prioritized, self-contained implementation plans generated by the `improve-animations` audit workflow and augmented with **Apple Fluid Interface Design** principles.

## Recommended Execution Order

1. **Plan 002 (Token Foundation)**: Establish baseline `--ease-out`, `--ease-apple-fluid`, and `--duration-*` variables in `static/style.css`.
2. **Plan 006 (Apple Fluid Foundation)**: Add instant `:active` pointer-down feedback (`scale(0.97)`), glass translucent depth (`backdrop-filter: blur(20px)`), and fluid curve foundations.
3. **Plan 001 (Performance Core)**: Replace all un-accelerated `transition: all` rules across CSS and template files.
4. **Plan 004 (Modal Physicality)**: Apply Apple fluid curves to modal dialogs.
5. **Plan 003 (Accessibility)**: Update `@media (prefers-reduced-motion)` rules.
6. **Plan 005 (Loading Micro-interaction)**: Add the GPU-accelerated button spinner.

## Key Apple Fluid Design Principles Applied

- **Instant Pointer-Down Response**: Feedback fires on `pointerdown` / `:active` (100ms scale 0.97), never waiting for `click`/release.
- **Translucent Depth & Materials**: Navbars and modals use `backdrop-filter: blur(20px) saturate(180%)` to feel like physical layers.
- **Interruptible Curves**: Motion uses Apple's signature fluid response curve `cubic-bezier(0.16, 1, 0.3, 1)`.
